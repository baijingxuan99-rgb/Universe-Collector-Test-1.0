# V17 · 《窗开的时候》家庭排练

本版落实 V16 试玩反馈。双声草稿和院门取证组成同一次练习，主线当天可交付。中途回小店会保存已经采到的声音、证词和试演选项。

1. 玩家照常把咖啡勺和鸟鸣接成两句，收录「双声草稿」。母亲正提着篮子回来，门响盖住了练琴尾音。笔记和画室立即出现「去院门试门声」，院门热点高亮。
2. 先拨门闩，再按住门闩推门，分辨短响和门扇长声。南内尔核对鸟停以后才推门，练习琴给出第 4 格的返场记号。
3. 玩家排好门声、开门时机和琴声间隔，按「试演一次」。若提前返场，四格时间轴将第 3 格标成「余响＋琴声」。修改任意选项后可立即重演。正确试演解锁交付和母亲卡。
4. 以后一个可探索日回画室，或从收藏手记点「家庭合奏 · 再听一遍」，听家人自然重演作为可选尾声。尾声免扣探索次数、无额外奖励，独立于后续主委托。

灰盒仍使用浏览器合成音，静音可看完整证据与冲突。自动化覆盖当天交付、回店刷新后续做、正确试演后才能交付、跨周末可选尾声、奖励去重，以及快进与其他章节的回归。
