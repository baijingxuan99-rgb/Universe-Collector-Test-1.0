星级 规则

示范拍不计分；只有正式音符有 Perfect、Great、Miss。现有原型的有效窗为 ±180 ms，建议先测 ±65 ms Perfect，65–180 ms Great，另用 ±50、±80 ms 对照。建议加全局音画延迟校准与重试入口。有效时间窗内只对正确动作给判定，一拍只计一次；无匹配的按键给「空按」反馈，避免玩家误以为打中了音符。星级保存单次最高纪录，不拼接跨局表现。旧版存档没有逐拍精度证据，建议仅迁入可确认的完成纪录（1 星），原有演出落款另存。重演免费、无体力、同曲可立即重试。高品质奖励可以优先考虑纪念性用途，例如唯一的回看墙陈列物或额外演出画页；具体效果待定。

唯一人物卡

  • 母亲。第三章第一份必经委托由安娜·玛丽亚在旅途记忆中委托，成功后固定发她的一张紫卡。
  • 姐姐与父亲。商店玩法开放后，从全游戏任意章节和任意营业模式的有效营业结算中各有小概率遇到。遇见即解锁对应紫卡，无需购买、交谈选对或带指定商品。角色来访走独立结算事件，和琴房之夜、来信客等可同夜排队出现。
  • 莫扎特。三个唯一紫卡标记齐全时立即补发金卡，与皮肤分别记录。用全局唯一角色 ID 判重。刷新、重播弹窗、重复遇见、先收齐两个商店角色再做母亲委托，均只授予一次。
  • 卡册与测试。落卡立即入卡册。三张来源明示，遇到后的选项用于读人物小传和回看。测试菜单提供「指定南内尔来访」「指定莱奥波德来访」，只用于隔离试玩档，不消耗正式遇见次数或写入正式收藏。

可参考的游戏

  • 《Rhythm Heaven》任天堂说明书用关卡窗显示成绩与奖章，并用奖章开启额外内容。这里可借鉴三幅画框各挂最佳成绩，额外奖励在墙上单独揭幕。
  • 《BanG Dream!》游戏内帮助存档分别定义 Full Combo 与 All Perfect。这里可借鉴让二星与三星直接对应两类判定，省去模糊的总分线。
  • 《集合啦！动物森友会》博物馆介绍把发现与长期展示连接起来。这里可借鉴卡册里看见来源、已收藏和缺位，使偶遇本身变成可回顾的纪念。
