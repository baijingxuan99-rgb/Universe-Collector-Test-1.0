# V12 · 委托笔记与对白

| 位置 | 内容 | 操作 |
| --- | --- | --- |
| 左上 | 当前委托已发现的摘要，按取得顺序显示 | 交付或结束该委托后清空。琴房每日独立，未做完的当天记录可继续 |
| 底部 | 角色对白、现场观察和直接操作 | 走到热点再读或操作。现场试样的结果同步进入摘要 |
| 右下 | 斜放的半弧形笔记本 | 玩家自行打开。比对候选、试听已收线索、提交答案在弹窗内完成 |
| 笔记弹窗 | 当前推演页 | Esc 或合上笔记返回场景。错误提交保留已发现的证据 |

纸星星可先在笔记挑纸样，合上后到窗框或折纸台测试，最后回笔记提交。月亮糖可先查任意证据，两条齐后到笔记选包裹。巴黎琴房的三天各自用独立摘要，切到下一天不会翻出前一天的证据。主线剧情线索页暂留到有具体内容时再评审。

第三章的角色卡计划用同一本笔记的卡夹页承载。人物页、章末解锁和卡牌玩法均处于方案评审阶段。
