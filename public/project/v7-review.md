# 《宇宙收藏家》V7 画册版 · PPT 玩法融入评审

**结论｜有条件采用。** 把《Music life》的画册、情景节奏和角色视角接入现有探索闭环。第一次游玩由归位直接过渡到合奏，完成后回到星光小店。选曲、角色视角和成绩放在收藏手记，供玩家主动重温。

评审基线为上传的 `demo004(1).pptx` 与 V6 离线原型。PPT 的按钮、曲目难度和角色能力属于设计意图。V6 规则以实际代码为准。预测的理解度、兴趣和复玩意愿有待真人测试。

### 优先解决的三处冲突

1. **选曲和选角色会截断第一次探索的因果。** 莉丝已经把玩家带到窗边。此时多一步选择就会延后「我找回的旋律被唱出来」的反馈。把首次合奏留在街角，曲目与角色卡在通关后解锁。用无引导试玩验证玩家能否解释「合奏为什么在这里」。
2. **图内提示要比装饰先被看见。** 原画已有大量星芒，交互星必须有清晰的运动终点，路灯信号也要独立可辨。首轮保留掌心与灯弧轮廓和两个有文字的按钮。观察玩家看完两次示范后能否用对两种输入，尤其是静音和手机场景。
3. **演出表现和夜间经营承担不同的压力。** 命中应该影响演出反馈。晚间策略来自库存、周转金和客情。让成绩影响进货、概率或价格，会把节奏熟练度变成经营优势，较难判断玩家是否真的因客情而换门面。先让收藏回放和剧情视角承接复玩动机。

## 2. 平衡复核

## 4. 最小验证

选 5 位目标玩家作为第一轮可用性试验，记录实际耗时和动作顺序。

- **首次进梦境。** 目标为 5 分钟内从异常线索走到第一次合奏或带拍结算；至少 4 人能说清三段旋律如何进入下一步。
- **合奏。** 至少 4 人看完示范后能独立尝试正确的两种动作。记下第一次错按发生在看不见、看不懂还是来不及。记录主动带拍和手动选择，避免把通关率等同于喜欢。
- **收藏回看。** 通关后能找到曲目、说明重奏与重听的差别，并独立返回原流程。若画册被误认成另一条必做主线，先调整入口或文案。
- **第三晚。** 在库存和现金相同的情况下展示冷清与热闹客情，观察玩家是否改变门面和备货，并能说出可能亏掉的 2 币。这里验证经营选择有没有被新增的音乐内容掩盖。

本轮覆盖探索、叙事、界面、经济和素材复用。节拍延迟的设备差异、控制器、完整歌曲制作、角色平衡、多人和发行范围留待各自验证。
