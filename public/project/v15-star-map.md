# V15 · 测试快进、委托笔记与星图

## 独立测试档

从工作台的「测试快进版」进入。离线包可直接打开 TEST.html。测试档沿用之前的测试存档，与普通试玩隔离。快进按钮只在可操作时出现。

| 按钮 | 结果 |
| --- | --- |
| 跳过探索 | 完成本段探索或当前委托，走原有交付和奖励。第三章的隔日取证也可在测试档直接完成；下一件仍从下个可探索日接 |
| 跳过合奏 | 按带拍结算，记录 1 星，既有更高成绩保留 |
| 跳过经营 | 尝试按当晚需求采购、上架、开门，自动接待余单。条件不够时按休息结算。结算可查看，再一键到次日 |

## 第二天的笔记

接下纸样委托后，右下角高亮提示打开笔记。第一次在笔记里操作之前会显示三步提示。选任一纸样即可在同页测窗宽或压折痕，三张卡分别保留结果。两个测试都做完才可交付该纸样。现场的窗框和折纸台也可继续用于测试。

## 线性路线与星图

街角委托完成并到第 4 天后，下一可探索日自动进入巴黎琴房。首次结算巴黎琴房合奏即自动抵达莫扎特画室。次日探索优先进入当前推进中的章节。左上地图用一颗莫扎特星球收纳三个章节，缩略图沿用现有场景美术。已解锁的章节可自由前往，正式营业和正在演奏时暂不可移动。
