0. 如何使用与更新

  • 【确认】用户已明确提出的方向。
  • 【建议】为使Demo可实施而补充，可随测试替换，不视为用户已确认。
  • 【待定】尚缺决定；本文给出临时默认值以免阻碍开工。
  • 【待验证】需要可玩原型和真实试玩判断，不能由文档证明。
  • 每次修改更新版本、变更记录及受影响章节；失效方案移入变更记录，不同时保留两套有效规则。

1.1 一句话介绍

玩家进入历史人物的梦与想象，通过轻巧的环境谜题收集素材，把它们放回合适的位置，亲手促成一次作品呈现。

1.2 设计取舍

  1. 玩家行动要改变事件或场景，而非只有图标点亮。
  2. 所有必需答案均有游戏内证据，不要求预先懂历史、乐理。
  3. 最终音乐要能让玩家感知自己的收集与归位；不把系统编排冒充自由作曲。
  4. 主线可有适度挫折，但允许提示、局部重试与操作辅助。
  5. 优先做好一个闭环，不靠增加交互点、长对白、粒子或等待延长时长。

2. 整体玩法框架

2.1 标准关卡循环【确认】

进入情境 → 发现异常或人物需求 → 观察／对话／使用道具 → 触发事件 → 收集本关素材 → 依据线索归位 → 系统呈现成品 → 故事收尾与奖励。

素材只在当前关卡范围使用。终章／BOSS可使用其所属章节允许的素材，但跨章节不通用。鉴于本轮“章节／关卡”称谓尚未统一，Demo只实现第一关本地素材，不提前制作跨关背包。

2.2 素材与归位【确认】

  • 素材可以是乐器、音色、节奏、音调、乐句或作品片段；不要求每关同时包含所有类型。
  • 系统负责音乐编排，玩家主要负责收集和归位。
  • 特定关卡允许同类替换；兼容性需预先配置，不能仅靠同音高认定所有声音可直接替换。
  • 玩家选择的合法素材进入最终结算成品；本关不开放替换，先验证固定编排。
  • 错误归位可撤回，保留已完成部分，不消耗素材【建议】。

2.3 终章／BOSS【确认】

综合之前学习的解谜方法及可用素材，具有一点操作或解谜难度，配合作品与故事收尾。不以高频连点作为默认方案。严格节奏挑战、命中率与稀有奖励的具体关系后续单独验证。

2.4 长期奖励【确认／待定】

  • 主线进度解锁后续内容。
  • 历史人物皮肤或独特装扮为纯装饰；用户曾指定对应挑战关胜利获得。
  • 辅助道具有功能；首关奖励星星糖。
  • 首关不提前发放莫扎特挑战装扮。后续主线、挑战关的奖励分配待定。

3. 第一关：梦里的三颗星星

3.1 叙事设定【确认】

这是一场莫扎特的梦。梦中，他以小孩子的形象出现在法国小镇，探索夜晚的街角。

一个年轻女孩坐在屋外的储物箱上晃腿、看星星，等待收工的妈妈。妈妈整理屋外杂物，嘴里哼着曲调，女孩轻轻附和。妈妈腿边蹭着一只黑白猫，身上有星星纹路。

女孩告诉小莫扎特，这首曲子是星星教给她的，并赠送一颗包着糖纸的星星糖。

三个关键“星星”：

  1. 女孩赠送、手中包着糖纸的星星糖。
  2. 天上星星在地面水池中的倒影。
  3. 黑白猫身上的星星花纹。

成功收集后，聚光灯下的钢琴显现；玩家前往归位，完成《小星星变奏曲》片段的梦中演出。通关获得可装备的星星糖。

3.2 史实与艺术边界

本关是虚构梦境，不表示莫扎特真实地从女孩、猫或池水处获得作曲灵感。不在场景中标注“1760年”；现实幼年形象与成年作品出现在同一个梦里无需解释成历史时间线。

K.265以已有歌曲《Ah, vous dirai-je, maman》为主题，包含主题与十二首键盘变奏，并非协奏曲；莫扎特不是主题旋律的原创者。基金会目录定年为维也纳1781–1782。具体创作缘起未确定。现代“小星星”称呼仅用于玩家界面，人物对白称“这首曲子”。

结算短知识卡【建议】： “你熟悉的《小星星》旋律，在莫扎特之前已经流传。他以《Ah, vous dirai-je, maman》为主题，写下十二首键盘变奏。本关是一场想象中的梦。”

3.3 视觉与成本约束

【确认】整体画面近乎静止；水纹、女孩和猫有少量动态。这里的“静止”指氛围和表演克制，不阻止玩家移动与交互。

【确认】场景聚焦18世纪法国风格的小杂货店外部，店门已经关闭；包括房子、树木、池塘和路灯。女孩与箱子在店门一侧，妈妈与猫在另一侧，池塘位于前方偏左，暗处预留钢琴显现位置。具体距离与通行空间以灰盒测试调整。

【确认】采用小莫扎特背后的第三人称跟随镜头，略微俯视，不锁死机位。整体场景收成一块小街角，外围用白色迷雾包围，结尾通过镜头调动／拉远显露梦境边界。自由环绕角度、距离、遮挡处理和转向方式仍待定；不能继续按只有一个可见角度制作资产。

【确认】纯3D、无描边Low Poly；从可爱简单的造型调整为略写实、优雅的比例与绘画色块，参考用户提供的《剑与远征》方向图片。保留简洁体块、哑光质感，避免堆叠砖瓦、花叶等细节。以最新上传的白雾街角概念图作为构图与气氛参考，并非逐片复刻其绘画细节。

【建议】仅保留水纹、晃腿、猫蹭腿／安顿、妈妈简单整理循环。钢琴以灯光揭示。建筑无需可进入的室内；跟随镜头可能看到的侧面、背面与屋顶应保证完整轮廓。详细美术与资产约束见第13章。

3.4 玩家目标如何自然成立【待验证】

目标不能仅靠开发者知道“需要三颗星星”。建议用一次可理解的因果演示：女孩赠糖→玩家查看→第一段音乐响起→女孩说“它们还会唱别的呢”→水面和猫花纹各有一次轻微回应。

不立即显示完整位置清单；素材栏第一颗亮起，余下显示两个柔和轮廓【建议】。这会提示数量，但不揭示答案。如希望完全隐藏数量，可在测试后删除轮廓。

试玩时重点检查：玩家是否知道可以继续寻找，是否理解寻找是为了接上曲子，而非随意找隐藏物。目标不明时先补短对白，不用增加闪光频率替代动机。

4. 第一关可实现流程

下表中的三类星星与钢琴为【确认】；具体取得机关、对白、归位方式均为【建议】，可替换。

阶段 时间预算 玩家行为 即时结果
入梦 0:00–0:25 移动，听见母女轻哼，靠近女孩 开始交谈
糖星 0:25–1:00 收糖并查看／拆开糖纸 第一段声音、素材栏更新，建立寻找动机
水星 1:00–2:00 观察水纹与成因，恢复清晰倒影 第二段声音，池面短暂聚光
猫星 2:00–3:15 理解猫的行为，放好软垫使其安顿 星纹完整可见，第三段声音，妈妈动作回应

此预算偏紧，试玩超过5分钟优先简化取得操作，不提高移动速度掩盖理解问题，也不强制跳过玩家。

4.1 开场对白【建议稿，均为虚构】

小莫扎特：“谁教你的？”

女孩：“星星。”

女孩递来包着糖纸的星星糖。

女孩：“喏，你也问问。”

查看后第一段声音响起。

小莫扎特：“它还真会唱。”

女孩：“它们还会唱别的呢。”

只需短文字气泡，无配音要求。妈妈和女孩的哼唱可先以单一旋律音源代替。

4.2 糖星：教学交互

  • 前提：与女孩交谈，获得本关临时星星糖。
  • 动作：点击／交互查看，再展开糖纸。
  • 反馈：星形显露，播放短乐句，获得“糖星记忆”。
  • 状态：糖未被吃掉或消耗；记忆是收集素材，糖是物品，避免结算凭空再生。
  • 首版无需独立背包页面；用一张轻量物品近景和现有素材栏完成。

4.3 水星：观察原因并改变状态

建议机关：挂绳末端碰着水面，持续造成波纹；将绳子挂回池边挂钩，波纹平息，倒影完整。此为幻想化小机关，须让接触与波纹因果在画面上清晰成立。

  • 证据：看见绳端与水面接触；波纹从接触点散开；旁边可见挂钩。
  • 正确操作：把绳子放回挂钩→倒影完整→点击收集。
  • 错误操作：点击散开的倒影不计失败，提示“水面晃得看不清”。
  • 简化备选：关闭持续滴水的小水壶／水口。若道具表达费力，灰盒直接点击源头切换状态，不做物理模拟。
  • 收集后普通倒影仍在，仅“星星记忆”被记录。

4.4 猫星：理解需求与使用物件

建议机关：猫一直蹭妈妈，星纹侧面难以完整看清。妈妈提示“小家伙，你的垫子在那边”。玩家将杂物上的软垫放进篮子，猫安顿后露出星纹。

  • 证据：篮子空着；猫停留在软垫附近或闻它；妈妈一句短提示。
  • 正确操作：拿软垫→放篮子→猫走入／切换姿态→查看星纹。
  • 反馈：短乐句＋第三个素材标记；妈妈得以继续收拾，回应玩家行动。
  • 不做追猫、抓取判定或点击时机；猫不是移动靶。
  • 水星与猫星在获得糖星后可任意顺序完成。

4.5 钢琴与归位

  • 三个记忆收齐后，暗处钢琴灯亮，响起一个引导音；不强制夺走镜头。
  • 接近钢琴出现交互提示，打开同一场景内归位面板。
  • 首版建议：三枚星星承载三段乐句，边缘星座线可以连续连接；玩家按证据放入三个位置，点击可试听。
  • 开头与再现可能音乐相似，不能只靠听觉区别。图形给出公平解题依据，音乐提供结果验证。
  • 错放只标出断开的连接；可撤回、不清空、不扣分。正确片段保留。
  • 最小实现备选：玩家点击三枚已收集星星依次入谱，系统自动排序。仅当归位机制拖慢开发时采用，标记为“演出触发”，不得宣称已验证归位解谜。
  • 不要求玩家演奏整曲。完整指本次短演出在乐句上完整，不指十二首变奏全部播放。

4.6 演出与故事结束

以约35–45秒为首版预算：熟悉主题的完整短乐句→第一变奏对应完整乐句→音乐性收束。具体剪辑依所选谱本与速度调整，不能硬切音频凑时长。

糖纸、池水、猫纹路按乐句轻微亮起，表示收集成果参与本次演出；原版钢琴负责主要音乐，不声称猫声是原曲素材。母亲走到女孩身边，女孩从箱子下来牵手；可用姿态切换替代复杂动画。

建议收尾对白：

女孩：“妈妈，星星今天唱得不一样。”

妈妈：“走吧，回家了。”

音乐完成后再显示奖励，避免弹窗打断结尾。

5. 奖励：星星糖

5.1 已确认能力

装备星星糖时，周围环境静止，解谜点附近仍有轻微动态，帮助观察。后续其他关卡使用会限制时间。

5.2 实现规则【建议，待确认】

  • 装备赋予能力，主动使用进入“星星时刻”，而非装备后永久自动开启。
  • 冻结环境装饰与角色循环，不冻结玩家、界面或完成谜题必需的逻辑。
  • 当前能推进的线索附近保留轻微动态；已解决线索不重复提示，尚不可访问的线索不提前泄露。
  • 普通状态也有足够静态线索，能力用于定位，不直接回答道具如何使用。
  • 后续有效时长、冷却与次数暂不填数值；不在未测试前加入消耗经济。

5.3 教学关的能力展示【建议】

主流程临时持糖并记录星星，结算正式解锁为可装备道具。初版可只做奖励提示；若实现演示，通关后提供可跳过的短展示：普通动作暂停，钢琴附近仍有一处轻动。该演示不再新增收集任务，也不阻挡通关。

注意：本关原本近乎静止，演示前后必须有可辨差异。不能仅靠动态表达必要线索；后续需要考虑减少动态设置下的替代提示。

8. Demo制作顺序

目标是开始做出闭环，不承诺一天完成正式美术和全部能力系统。引擎使用团队最熟悉且已可运行的方案；原PDF列Unity，但不据此认定当前已确定。

P0：先能从开始玩到结束

  1. 搭一个3D灰盒场景，放好女孩、水池、猫、隐藏钢琴四个区域；验证背后跟随镜头下的通行、视野和遮挡。
  2. 实现移动、距离交互、短对话。
  3. 先用点击切换状态完成三颗星星的收集；每次立刻有声音和可见变化。
  4. 三星齐后显现钢琴；点击打开归位，完成后播放临时音乐。
  5. 展示结算与星星糖奖励；一键重开完整测试。

P1：让它真正像解谜

  1. 加入水纹成因与修复状态。
  2. 加入软垫→篮子→猫安顿的因果链。
  3. 加入三槽归位证据、试听与局部纠错。
  4. 补齐角色回应和最基本提示。

P2：验证最大反馈

  1. 制作主题与变奏的可听对照，按乐句调整演出。
  2. 加灯光、母女团聚、少量动态；删除无助于理解的装饰。
  3. 有余力再做星星糖能力演示，不让它拖延首轮试玩。

13.1 当前有效方向与探索记录

历史探索：TOEM式彩色2.5D、纸片角色／简模组合、固定正交镜头、全3D描边均为早期备选，现不作为制作基线。Chicory、Carto、Snufkin用于早期线条与色彩探索；NAIAD用于柔和环境、冷暖与体积参考，Hole Is Mine用于简洁造型参考；后续以用户提供的优雅比例参考和白雾街角概念图为准。以上是视觉借鉴，不代表这些作品采用相同制作技术。

13.2 造型、配色与渲染建议

  • 房子：奶油色墙面、灰紫屋顶、关闭木门、暖窗、简化招牌与门廊；主要靠比例和大轮廓建立法式街角气质，不逐块建砖瓦。
  • 地面：蓝灰石路与少量池沿石，通行区清楚；地砖优先材质或少量模块表达。
  • 树木：低面树干与成团树冠，层次靠体块和配色；花草只做局部点缀。
  • 池塘：小型、不扩为河道；蓝灰水面，独立星星倒影和少量水纹，首版无需实时反射。
  • 路灯与窗户：柔黄暖光，帮助分隔物体；夜景仍需清楚辨认三个线索，避免纯黑重阴影。
  • 白雾：外围浓、内部清，保留小街角被包围的轮廓；先用少量雾片或简化效果验证跟随与拉远两种镜头，避免遮挡解谜点。
  • 钢琴：深蓝紫主体，通过光斑和背景明度分离；显现使用灯光渐亮与模型状态切换。
  • 三种星星：糖为柔黄实体与糖纸，倒影浅黄略拉长，猫纹奶白且边缘自然；以共同轮廓建立联系，避免全部常驻发光。

起始色板【建议】：夜色 #35445F，墙面 #E9DFC9，屋顶 #8B7891，地面 #929FA9，暖光 #F4D57B，人物点缀 #CF8F86。需在同一场景里统一测试，不视为最终锁定。

13.3 拓扑、分组与镜头验收

  • 建模编辑网格以四边面为要求，输出统计：顶点、四边面、三角面、N边面、总面数及引擎三角形估算。低面数优先保证剪影和遮挡关系，不在未测试前承诺固定总面数。
  • 适量倒角用于关键轮廓；避免全场统一细分。圆润树冠可用低分段立方球等方式维持四边面，不依赖三角面球体直接充数。
  • 场景、角色分别分组；建议场景下再分建筑、植被、水体、道具、灯光、雾与摄影机。材质与模块复用。
  • 第三人称镜头需要测试角色贴墙、绕树、靠近池边、接近店门时的视野与碰撞；具体环绕范围后续决定。
  • 结尾镜头在音乐收束后显露白雾边界；常规游玩不因演出机位破坏交互控制，镜头接管时机待测试。
  • Blender搭建属于制作任务。用户曾授权清理场景Cube并创建检查子agent，但当时会话无Blender连接，未实际删除或搭建；不能据此把资产标为已完成。

13.4 成本与范围记录

此前纯3D方案的可展示首关粗估为12–21人日：风格测试1–2，场景3–5，三个人物3–5，猫与必要动作2–4，灯光水面与整合3–5。该估算基于固定镜头、小场景和熟悉工具的团队，不含玩法程序、音乐与完整测试，也不是报价。现已改为跟随镜头，需要重新估算背侧资产、遮挡处理、碰撞及性能工作，不能直接沿用原总数作为承诺。

早期纸片方案11–18人日、二维分层9–15人日、复杂全3D描边19–32人日仅保留作探索记录，范围和当前方案并不完全相同。玩法灰盒的临时视觉曾估1–3人日，亦非交付期限。

首个视觉样板应包含：一块地面、杂货店墙门与暖窗、女孩与箱子、妈妈与猫、小池塘、树和路灯；先验证无描边可读性、夜景清新程度、跟随镜头与三个线索的辨识，再扩充细节。

14. 暂定支线玩法｜合成与梦境收藏（灵感储备）

定位：为将来拓展保存讨论，不代表已经立项、已验证好玩或纳入首个Demo。用户已明确的是道具收藏与消耗用途、通关后可持续游玩的目标；下述名称、回响材料、棋盘和配方均为建议。

14.1 用户希望达成的目标【确认】

  1. 关卡关键道具除点亮图鉴外，还能用于支线消耗，建立收集后的用途。
  2. 玩家通关主线解谜后，有一个可以反复玩的小游戏。
  3. 小游戏本身具备乐趣，体量保持小；二合、塔防曾作为候选方向。
  4. 本阶段只记录，为未来拓展储备，不挤占主线闭环验证。

14.2 道具、图鉴与消耗的关系【建议／待确认】

层次 用途 消耗规则
剧情关键道具／星星记忆 解谜、叙事、归位 主线唯一道具不因支线消耗导致卡关
永久图鉴记录 首次发现、故事、声音与收藏展示 点亮后永久保留，材料消耗不抹除记录
可消耗材料 合成、人物愿望、场景装饰 建议称“梦境回响”，作为关键道具的可重复副产物
能力奖励星星糖 装备与提示能力 与合成材料分开，不因合成丢失能力

“消耗本体还是回响”尚未由用户定案。使用回响是减少纪念品损失顾虑和主线冲突的建议，不应写成强制世界观。若最终消耗实物，必须限定可重复获取的副本，定义补给和数量展示。

主线素材本关使用的限制继续有效；支线材料能否跨关、跨章节流通另行确定。

14.3 建议整合方式：星光工坊／星光合成

主线演出结束后，通过杂货店门前的小音乐盒开启独立小游戏。镜头可靠近桌面或打开棋盘界面，不需要开放已关闭的杂货店内部。每局约3–5分钟为测试起点，结束后可随时再开，通关状态不回退。

建议循环：探索梦境并发现关键道具 → 点亮图鉴、解锁材料或配方 → 游玩合成小游戏 → 获得成品／回响 → 完成人物愿望、制作装饰 → 回到被改变的梦境。

小游戏开局免费提供基础材料，支持反复游玩；不要求反复跑已解决的主线捡材料作为入场门票。通关后摸猫、聊天、听水声等互动可少量补给，但只是可选奖励。结算只带回哪些物品、失败是否保留产出、奖励如何防止无限膨胀均待设计。

14.4 小型合成原型【建议，规则未锁定】

  • 棋盘：4×4格，显示下一枚材料，玩家选择落点。
  • 合成：二同合一与三同合一均保留候选；此前建议先试三枚同级相邻合一，合成位置由新落点决定，用以测试空间取舍和连锁。
  • 等级：3–4级即可；约20次投放或完成目标作为一局结束条件，具体需测试。
  • 乐趣：为后续落点留空间，选择即时合成或准备连锁，逐步改善自己的摆法。
  • 音乐：完成阶段目标后打开预先编排、同步的音乐层，局末短演奏展示成果；不直接将随机材料拼成未经校验的旋律。
  • 重玩变化：少量不同初始障碍、局内目标、连锁挑战；随机材料池需受控，新增道具不应使组合概率失衡。
  • 最高级道具可交付离场、释放格子，或局末统一结算；两种机制需原型比较，不同时设为有效规则。

早期另有“合成音符→形成小乐器→自动演奏”的版本，可作为更轻量的表现备选。若采用具体道具合成，音乐仍可保留为阶段反馈。

14.5 合成链与人物愿望示例【灵感，不作配方承诺】

起点 暂定合成链 支线愿望／消耗结果
星星糖回响 星星糖→糖果罐→星糖灯 女孩想留住星光；完成后箱子旁挂一盏灯
水中星光回响 星光→星光瓶→漂浮星灯 装饰池塘或制作池边风铃，互动增加柔和声音
猫咪星纹回响 星纹→星纹布片→猫咪软垫 妈妈想给猫一个睡觉处；店门旁出现猫窝，猫可安顿

配方中的形态与转化需以梦境逻辑解释；原型先做一条链和一个愿望。主线安顿猫的篮子／软垫与支线奖励猫窝应有视觉和用途区别，避免重复解同一问题。

14.6 奖励与主线体验边界

  • 主线首次演出应提供完整结尾与既定奖励；小游戏是通关后的可选延伸。
  • 装饰结果尽量实际出现在场景里，使消耗有可见意义；是否影响再次播放的结尾镜头待定。
  • 可考虑花盆配色、星灯样式、小配饰与声音收藏；莫扎特挑战装扮仍沿用挑战关奖励方向，避免奖励来源冲突。
  • 图鉴补全、道具数值、皮肤收集不宜同时成为强制负担。无体力、订单等待和长合成链作为首轮原型默认。
  • 支线完成后，仍可通过布局、连锁和音乐反馈重玩；不能仅靠持续增加任务维持点击。

14.8 未来验证与最小范围

最小链路：首次发现星星糖 → 图鉴点亮 → 通关后开启一块合成棋盘 → 合出星糖灯 → 完成女孩愿望 → 灯留在门口 → 可以重新开局。

只制作一种基础材料、3–4级合成、一张棋盘、一个消耗愿望和一个场景装饰。先测棋盘本身，再接入资源与奖励。

需要回答：玩家是否主动再开一局；是否能说明一次摆放决策；棋盘会不会很快堵死；音乐变化是否可感知；材料是否有用途却不造成刷取压力；玩家是否能区分图鉴、剧情道具、能力与消耗材料。试玩记录用于决定是否立项，不能把“可以无限开局”等同于“值得反复玩”。
