# 宇宙收藏家 · V18 迭代范围（2026-11-23）

## 已确认的创作方向
- 产品正式名称《宇宙收藏家》；“宇宙”表示可以拓展的主题世界（音乐、艺术、小说），不是太空模拟。
- 保持中小体量独立游戏的制作范围。首个完整切片聚焦莫扎特音乐宇宙。
- 统一体验语言：观察 → 理解 → 组合声音 → 改变世界。
- 重要剧情人物卡通过可验证的剧情、委托及有意义交互稳定获得，不以低概率营业偶遇作硬门槛。
- 道具的独立音高与音色用于收集、推理、组合；完成后在演出场景听基于正式曲谱编排的版本。当前浏览器合成音属于原型音源，录音须独立制作并核对授权。

## 三个平台
- 正式试玩：/play/，不包含测试快进
- 玩法实验室：/lab/，用于 A/B 与独立机制验证
- 开发工作台：/workbench.html，索引版本、策划与历史实验

## 迭代次序
P0：修正普通订单真实商品类型；不能提前要求未发现的商品；将主线人物卡改为确定性奖励；梳理入口与首章音高试听。
P1：以一次独立音乐经营事件验证探索到夜间营业的策略迁移，并采用横向测试而非直接叠进完整经营。
P1：将首章环境状态变化、声音拼接与角色演出反馈联动；测试两种需求下是否改变玩家选择。
P2：通过测试后再扩展其他宇宙和高成本制作系统。

本文件是迭代范围与验收边界，不代替运行验证或真实玩家测试。
