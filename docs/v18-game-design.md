# 《宇宙收藏家》V18：经营策略、解谜模型与音乐-经营统一设计
日期：2026-11-23
状态：实施蓝图（与仓库现有 V18 原型补丁、测试区分）

## 1. 产品北极星
一款中小体量、以人物经历为中心的叙事解谜与小店经营游戏。「宇宙」是音乐、艺术、小说等不同主题世界；目前优先制作莫扎特宇宙。统一动词：**观察 → 理解 → 组合声音 → 改变世界**。

玩家愿望→梦境观察→获得物件音高／关系→组合出片段→正式音乐演出→留下收藏和经营能力→小店响应客人→下一封人物委托。剧情唯一物、永久发现与可售副本永久分离。

## 2. 经营策略应设计的八个维度

| 维度 | 玩家知道什么 | 可作决策 | 付出与风险 | 探索回流 |
|---|---|---|---|---|
| 需求与承诺 | 明晚预约量、客情、可信度 | 接预约／保守估计／拒绝可选加单 | 保证订单与放弃客流 | 顾客来信触发专属调查 |
| 备货与商品组合 | 每种 SKU 的价格、进价、需求 | 把预算放在刚需、主题品或补救品 | 现金、仓位、库存积压 | 探索解锁新品或替代性供给 |
| 货架与空间 | 货架／仓库格数 | 多品类混搭／集中铺货／腾出展示位 | 错失其他商品需求 | 物件或委托解锁空间改善 |
| 营业主题 | 天气、客流、主题品 | 普通／街坊拼单／橱窗／节目单 | 固定费、失败概率和高级品押货 | 乐句与作品影响可选主题 |
| 服务操作 | 顾客数量、找零规则、店员速度 | 自己处理／雇佣／快捷服务 | 资本与交互深度 | 故事人物/技能改善服务，非硬数值剥夺 |
| 音乐安排 | 顾客停留时长、噪音源与空拍 | 短句引客／完整句留客／留白避噪 | 两类顾客需求不能总兼顾 | 白天学过的音高、间隔和听辨规则 |
| 长期投资 | 升级价格、额外订单上限 | 扩货架／开后厅／雇工／留现金 | 回本周期与丧失流动性 | 解谜奖励可开放一个新经营动作 |
| 探索行动预算 | 白天 0–2 次探索、可选手作 | 主线调查／回访委托／救急生产 | 当天的其他探索机会 | 决策在下一晚接受现实反馈 |

**设计上区分**「高阶策略」（选经营主题和库存组合）和「低阶操作」（重复点采购/结账），让自动化节省劳动但不替代真正选择。

## 3. 为什么玩家会选择不同策略：现有 V17 参数核验

按店铺现有方案相对于普通营业的**条件增量期望利润**（商品已解锁、库存充足、可正常开门，且未计资金占用机会成本）：
`E(额外利润) = 到访率 × [额外销售毛利 + 订制费] − 陈列费`

| 模式 | 客情冷清 p=.25 | 客情寻常 p=.50 | 客情热闹 p=.75 | 核心诱因 |
|---|---:|---:|---:|---|
| 普通营业 | 0 | 0 | 0 | 规避额外投入，不追加风险 |
| 街坊拼单（2 星糖，来访概率 p+.20） | +0.9 | +1.4 | +1.9 | 无陈列费，小量额外货，低风险 |
| 纸星橱窗（3 纸星，费 2，概率 p，成功增毛利 8） | 0 | +2.0 | +4.0 | 适度风险，适用纸星供给充裕时 |
| 月亮糖橱窗（4 月糖，费 4，概率 p-.10-热度修正，成功增毛利 18） | −1.3 | +2.3 | +5.9 | 追求高收益，接受高额成本与波动 |
| 节目单 / 琴房之夜（2 份节目单） | 货币 0 | 货币 0 | 货币 0 | 角色机会与收藏，不以利润竞争 |

取舍不只比较期望值：还应同时展示最坏损失、需要额外占用的现金、货架、是否有商品库存、是否想见人物。现有月亮糖模式在寻常日仅较纸星模式多约 0.3 币期望收益，却有明显更大的单夜损失敞口；风险厌恶玩家可合理选纸星。冷清日若尚有货币需求，可选无费街坊拼单。热闹日且流动性充裕，月亮糖更吸引追求收入的玩家；如玩家想推进角色故事，则节目单仍有明确职责。

**后续调整目标：** 不追求几种模式在所有条件下严格同收益，而追求在不同客情、现金、货位、故事阶段出现不同优先顺序。监测某一策略跨 90% 日历场景总是最优的情况。

### 三种典型经济情景

**A 新玩家（50 币、10 格、仅星糖）**：可用普通/街坊，优先理解开店与找零；不能因未解锁纸/月商品而被预约惩罚卡死。

**B 已解锁纸星与月糖，现金只有 12 币**：即使今晚热闹，玩家也可能选择普通营业保留开门货与周转；灯夜橱窗 4 币费用和 4 件额外备货是机会成本。显示「本次决定能否开门」比隐藏的利润更重要。

**C 商品齐全、现金充裕、客情热闹**：可比较月亮糖(+5.9)与纸星(+4.0)以及琴房的非现金收藏机会，玩家动机影响选择。

### 平衡的实测方法

固定种子模拟至少 1000 个营业周，按「永远只选单一模式」「按客情最优」「优先收藏」「保守流动性」四类策略输出：现金中位数、零现金率、平均利润、缺货率、策略选择变化、后厅回本天数。再给玩家 3 个不同客情/预算情景，看他们能否说出有理由的不同选择。不要把测试模拟成功当成真人乐趣验证。

## 4. 可复用解谜模型：由观察产生可验证的推理

每个谜题包含统一数据：`目标状态 → 可观察对象 → 一组假设 → 玩家可试的改变 → 可复现的环境/逻辑结果 → 失败反馈 → 复玩变化`。

| 模型 | 心智流程 | 现有场景或最小示例 | 怎样验证玩家真的理解 |
|---|---|---|---|
| ① 因果修复 | 观察异常→找源头→移除干扰→看状态恢复 | 水池绳端起波纹→挂绳→倒影完整 | 玩家能指出波纹从哪里开始 |
| ② 行为需求 | 观察行为→推断需求→布置条件→等待回应 | 猫蹭腿→找软垫与空篮→安顿露星纹 | 玩家预判猫会做什么 |
| ③ 反证筛选 | 列出候选→采两条独立证据→排错→现场验证 | 纸样既要合窗宽又要可折 | 不是只靠重复交叉两个文字列表 |
| ④ 关系排序 | 观察先后/相邻→组织序列→试听冲突→局部改动 | 门声余响后留一格，再让钢琴返场 | 玩家能指出为什么第三拍不能奏 |
| ⑤ 对照实验 | 控制一个条件→观察差异→提出规律→应用新情境 | 门闩与门扇短长声音试验 | 先预测，再按按钮复核 |
| ⑥ 视角/位置验证 | 走近两处观察→发现同物不同结果→补全约束 | 琴边与门边试听同样乐句 | 玩家说明视角改变了哪一条判断 |
| ⑦ 信息来源可信度 | 区分证词、记忆与现场→交叉印证→改写解释 | 家人分别记得不同生活声音 | 不靠单条 NPC 说出答案 |
| ⑧ 音高拼接 | 听/看每物声音的高低轨迹→比前后连接→重排→播成完整主题 | 糖星、水星、猫星按音高片段归位 | 玩家能听出/看出顺序差异 |
| ⑨ 回访迁移 | 学一个规则→回到旧场景→新干扰打破旧解→改造原策略 | 白天学到留白，夜晚用来避开门铃找零声 | 不能直接照抄上次最优布局 |

尤其要区分：**状态变化谜题**（物体/环境真的改变）与**逻辑变化谜题**（玩家新理解揭示了之前错误的解释）。两者都可合格，核心在于证据与反馈是否可验证。

### 谜题制作检查表

- 目标：玩家是否在获得第一条线索之前已经知道自己想改变什么？
- 证据：至少两条互补证据；不能必须碰遍所有热点才允许操作。
- 操作：必须让玩家完成一个主动的预测/尝试，不能等同于阅读答案后点确认。
- 反馈：正确操作带来物体/人物/音轨变化；错误指出哪条假设失败，不清空正确部分。
- 弹性：静音、色觉辅助下仍可完成；提示分三级；退出可保存草稿。
- 复访：新委托改变约束而不是换名字；第一次玩家理解规则，后续玩家运用规则。

## 5. 声音统一机制

**道具层：** 每件物体定义自己的 `sourceId`、`notes`（MIDI 音高或相对音级）、`waveform/sample`、`duration`、`visualContour`。它是可观察、可对照的梦境声音，不宣称物件本身是历史原曲的真实录制音源。

**推理层：** 玩家通过相对音高、重复音、旋律走向、进入时序、留白与声部关系，将物体排成一段曲句。音高与音色同时反馈，音阶不是只有高低三种符号的按钮。

**演出层：** 选定合法的曲句映射到乐曲结构的 `phraseId`，用经过授权或自制的正式钢琴音源播放对应谱面；原型合成音可作为制作期后备。玩家已收录的音色可以在前奏或视觉回响里保留个性，但不冒充原曲真实乐器。

**经营层：** 从白天的成功解释里解锁少量可选的音乐营业安排（如短句迎客、完整句留客、留白避噪）。夜间机制先由独立的《把琴声挪一拍》验证，数据通过试验后再集成到主玩法，避免强行每晚新增一个音游。

## 7. 三个入口
正式游玩测试：`/play/`；玩法实验室：`/lab/`；版本与策划工作台：`/workbench.html`。三者都在同一 Netlify 站点。实验的独立存档不得覆盖正式存档。当前 V18 使用 V17 基础内容加独立补丁，以保留对比和回退通道，不代表正式发布质量。

## 8. 迭代验收闸门
1. P0 商品组合：2/3/4 日有真实不同商品；未发现商品不能在普通订单里卡人；店铺额外模式检查仍与商品一致。
2. P0 故事收藏：剧情发卡且只发一次，旧档与过去已随机得到的卡均能恢复。
3. P0 音高实验：每个星星物件听出不同音高序列，玩家能看见音高轮廓，错位可局部撤回，演出前可试听。
4. P1 最小音乐小店事件：白天获取线索后，玩家至少在两个顾客需求情景中选择不同音景；由实验收集反应。
5. P1 新玩家测试：5–8 位玩家，记录第一次有效操作、解谜解释能力、错题后重试意愿、夜间策略理由及下一次探索动机。
6. P2 美术、正式音频、多宇宙扩展和大规模内容量产均必须在前述闸门后推进。

## 9. 已实现/尚未实现的分界
V18 分支已加入局部 JS 规则覆盖、正式试玩测试入口和实验室入口；自动化静态/逻辑检查不能替代浏览器实机试玩。当前尚未制作正式录音、音符级别自由编曲、多宇宙章节、完整经营声音事件或全套埋点后台。正式发布前仍需重构临时补丁，补全浏览器端到端回归与 UI/音频体验测试。
